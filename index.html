Smart Campus Navigation System

Graph-based shortest-path prototype — Dijkstra’s algorithm implemented explicitly in Python

DSA Capstone · 3rd Semester CSE

Select a start and a destination, then find the shortest route.

Algorithm Trace

Order in which Dijkstra finalizes each vertex’s shortest distance from the source.

    Note on distances: edge weights are visually estimated from the supplied campus layout image at roughly 0.6 m per pixel (derived from the campus’s stated ~100-acre area) — they are not official survey measurements. See graph.py for the full explanation and raw data.

    Vertices = campus locations · Edges = walkable pathways · Weights = approximate distance (m) · Algorithm = Dijkstra (binary min-heap, O((V+E) log V))
